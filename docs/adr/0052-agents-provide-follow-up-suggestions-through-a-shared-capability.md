# Agents provide Follow-up suggestions through a shared capability

Agents provide Follow-up suggestions through one negotiated ACP extension and their existing sign-in (owner, 2026-11-14). Argo consumes that shared contract without provider-specific branches, generation prompts or SDK calls, and unsupported Agents offer no suggestion. Each Agent owns generation and suppression, so Argo needs neither a separate model service nor another client's identity.

# Composer redesign analysis — 6 October 2026

Source: current Paper Session component masters, not the exploratory board. Tokens remain `2737d693`.

The canonical In a Session, New Session, Main checkout and Plan expanded states now use the same 80 px card on desktop and phone: a 40 px draft region (12 px top, 16 px horizontal, 8 px bottom; 14/20 typography), then a 38 px toolbar (28 px controls and 10 px bottom padding). Toolbar starts at 15 px and ends at 10 px; left gap 4 px, right gap 10 px. Attach has a 16 px slot plus a 6 px trailing margin. Desktop Agent glyph is 14 px inside a 16 px lane, with 6 px text gaps. Mode and its label are muted. Phone shows Model only, optional Fast mark, icon-only Usage (clock-countdown, 16 px) and Context (14 px ring), and icon-only Mode without chevrons.

Card, desktop Plan tray and phone status chips share a new three-part shadow: `0 1px 2px #0000000f, 0 0 32px -8px #0000001a, 0 12px 24px -12px #0000000f`. The owner subsequently requested this same deep shadow on the bottom desktop envelope. Desktop tray/footer insets are 7 px per side, not 12 px. Plan header is 32 px, with 8 px leading/6 px trailing padding and 6 px gaps. Plan has only segmented progress, `Plan 3/5`, active step and caret; desktop expands its steps inside the tray, phone opens the existing Plan sheet. The expanded master was updated during implementation: rows are now 32 px minimum, with 12/16 text, 16 × 16 px icon lanes and 6 px gaps. The list has 4 px horizontal inset, 8 px bottom padding and a 264 px maximum height. Each row adds 4/2 px horizontal padding. The active row uses foreground at 5% and medium weight; completed text is muted, pending text foreground. The owner subsequently requested matching pending/loading circles: both now use the same 32 px vector viewport, radius 14 and stroke 4, rendered at 16 px on desktop and 14 px on phone. Longer plans scroll inside the envelope. Desktop expansion and collapse animate the measured list height over 200 ms with cubic easing, retaining hidden content for measurement and excluding it from accessibility when collapsed.

Phone removes the top and bottom envelope. Optional Plan and Agents chips are centred in a 28 px status line with 4 px bottom margin and 8 px gaps. Each chip is 24 px tall with 10 px horizontal padding, 6 px gaps, border, card background and the new shadow. Plan shows segments and `Plan`, without count or list icon. Agents shows Robot 16 px and `<count> Agents`. New Session replaces these with a checkout chip: GitBranch 16 px, muted `New worktree from` or `On`, foreground mono branch; no chevron. Controls remain available through sheets. Shell counts remain supported as an optional chip for existing functionality.

Existing image states remain separate attachment masters and must continue to preserve image removal, short errors and native scrolling. Menu content masters retain their current layout; trigger placement changes must not alter scrolling, adapters, checks, effort slider or selected states. SF Pro Text remains the font. Existing native device support is reused; no dependency or SDK change is needed.

The main visual risk is the phone toolbar overflowing at narrow widths or losing controls after removal of the envelope. Validate desktop/phone rectangles, single-line Model, actual native sheets and safe-area scrolling, and desktop inline Plan expansion. Exploratory option boards and unchanged queued/file/questionnaire scope remain outside this update.

Owner corrections after the Paper inspection: cap the editor at four 20 px lines, then scroll internally; remove the existing Session checkout popup; shorten the pre-creation trigger to `Local` / `New worktree`. Once a checkout path exists, show its created worktree directory name as read-only text even if change callbacks were retained. The owner subsequently clarified that the pre-creation menu itself should contain only `Local` and `New worktree`; its former Switch, search and branch list are removed. The read-only name permits up to 384 px on desktop, three times the earlier 128 px limit. It appears beside the phone status chips, which may wrap at narrow widths. These instructions supersede the inspected trigger wording.

Device verification caught native prefilled draft sizing, a platform import resolving to the web Slider, and native effort labels constrained to 4 px slots. Native initial height now respects explicit lines, content measurement handles wrapping, and internal scrolling starts at 80 px. The Slider import permits Metro to select its native implementation; native effort labels retain their full width. Browser verification also caught an unresolved SVG stroke and a dynamic accent prop leaving the Plan spinner blue; theme-aware SVG mapping and static responsive accent classes fix both.

The native mobile Plan spinner reproduces the web indicator's two-circle vector (32 px viewport, radius 14, stroke 4, 20% track opacity, dash 80/offset 60) at 14 px and its 750 ms linear rotation. This change is limited to the mobile Plan step; other native spinners remain native. Actual iOS rendering was checked. Desktop branch and Plan triggers omit the custom shadow entirely because combining `shadow-composer` and `shadow-none` did not remove that custom utility. Editor and bottom envelope computed shadows are now identical.

Final owner refinements: the checkout menu and trigger use Folder for Local and GitBranch for New worktree. The owner rejected the wider Attach layout: its original 16 × 28 px slot is restored, with only a centred 28 × 28 px hover/press highlight. The toolbar Agent logo uses an explicit 14 px SVG style to match the Usage icon's visible artwork and override the shared button SVG rule. The owner reverted the extra left padding: Usage keeps its original 2 px inset and the bottom envelope keeps 10 px right padding; the checkout trigger's right inset is 1 px so its 12 px chevron centre aligns exactly with the Send arrow centre. Browser measurement reports the same centre for both (776 px in the inspected frame). These refinements supersede the corresponding original master dimensions.

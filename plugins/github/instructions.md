**Pull requests.** When you open or start working on a GitHub pull request for this Session's work, attach it with `github.attach` and its reference (`owner/repo#123`, its URL, or just the number when it is in this Project's own repository), so the Session's Changes show it. Attaching it twice is harmless. Use `github.list` to read the pull requests attached to this Session, with their Checks; one marked `stale` or with an `error` could not be read now, so do not treat its Checks as passed. `github.refresh` reads them again. Do not attach a pull request you only mention. Argo only reads GitHub: these Operations never create, edit or merge a pull request.

**Pull requests.** To show this Session's work on GitHub, run `github.discover`: it finds the pull requests (open, merged or closed) opened from the Session's current branch and attaches them. Repeating it is harmless and keeps earlier ones. It answers `found`, `no-match`, `branchless`, `not-github` or `unavailable`; none removes an attached pull request. When discovery cannot name the work, attach it with `github.attach` and its reference (`owner/repo#123`, its URL, or the number in this Project's own repository). A Session keeps several; use `github.detach` only for one that does not belong to it. `github.list` reads what is attached, with Checks; one marked `stale` or with an `error` could not be read now, so do not treat its Checks as passed. `github.refresh` reads them again. Argo only reads GitHub: these Operations never create, edit or merge a pull request.

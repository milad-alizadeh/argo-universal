**Pull requests.** When you open or start working on a GitHub pull request for this Session's work, attach it with `github.attach` and its reference (`owner/repo#123`, its URL, or just the number when it is in this Project's own repository), so the Session's Changes show it. A Session keeps several; attaching one twice is harmless, and merged or closed ones stay until detached. Use `github.detach` with the same reference only for one that does not belong to this Session. `github.list` reads them. Do not attach a pull request you only mention. Argo only reads GitHub: these Operations never create, edit or merge a pull request.

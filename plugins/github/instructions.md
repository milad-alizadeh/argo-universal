**Pull requests.** To show this Session's work on GitHub, run `github.discover`: it attaches the pull requests (any state) opened from the Session's current branch. Repeating it is harmless, and after a branch switch the earlier ones stay. It never removes an attached pull request. Results: `found` attached some; `no-match` none opened from this branch; `branchless` no branch to look up; `not-github` the Project is not on GitHub; `unavailable` could not look (maybe sign-in), which says nothing about the pull requests. Otherwise attach with `github.attach` (`owner/repo#123`, URL, or number); `github.detach` is only for one that does not belong. `github.list` shows them with Checks: one marked `stale` or with an `error` could not be read now, so never treat its Checks as passed; `github.refresh` reads again. `github.files` and `github.diff` read a pull request's files. Argo only reads GitHub.

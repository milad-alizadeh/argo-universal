**Pull requests.** After opening a pull request, run `github.discover` with `unlessAttached: false` and wait for the result. If the pull request is on another branch, use `github.attach` with its exact reference. Use `github.list` or `github.refresh` to read current Checks. Treat stale or unavailable Checks as unverified. Use `github.files` and `github.diff` to read changes.

**Delegated PR handoff.** If the person requests a pull request, check for an existing one on the branch before creating it. Follow the repository's verification and review requirements. After attaching the pull request you opened, call `github.automationSet` with its exact reference, `kind: "fix"`, `on: true`, and `firstEnable: true`. Report the PR URL, attachment, tested head, current Checks, and the returned Auto-fix state. Auto-merge and Auto-archive require separate instructions from the person.

**Pull requests.** Run `github.discover` right after you open a pull request, in the same turn, before reporting it done: `gh pr create` alone leaves it unattached. It attaches the pull requests (any state) opened from the Session's current branch; repeating it is harmless and never removes one. Results: `found` attached some; `no-match` none; `branchless` no branch; `not-github` not a GitHub Project; `unavailable` could not look (maybe sign-in), which says nothing about the pull requests. Otherwise `github.attach` (`owner/repo#123`, URL, or number); `github.detach` only for one that does not belong. `github.list` shows them with Checks: one marked `stale` or with an `error` was not read, so never treat its Checks as passed; `github.refresh` reads again. `github.files` and `github.diff` read its files. `github.automationSet` turns auto-merge (`kind: merge`, GitHub's own, the only write), auto-fix (`kind: fix`) or auto-archive (`kind: archive`) on or off after the person confirms.

**Pull requests.** To show this Session's work on GitHub, run `github.discover`: it attaches the pull requests (any state) opened from the Session's branch, and repeating it is harmless. It answers `found`, `no-match`, `branchless`, `not-github` or `unavailable`; none removes one. Otherwise attach with `github.attach` (`owner/repo#123`, URL, or number); a Session keeps several, and `github.detach` is only for one that does not belong. `github.list` shows them with Checks: one marked `stale` or with an `error` could not be read now, so never treat its Checks as passed; `github.refresh` reads again. Do not attach a pull request you only mention. Argo only reads GitHub.

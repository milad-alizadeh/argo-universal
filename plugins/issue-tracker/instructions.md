**Issues.** When you start implementing an Issue, attach this Session to it with `issue-tracker.attach` and the Issue's number. The Issue can reach you as `#123`, as a link to an Issue in this Project's repo, or as one you chose yourself. Attach for the Issue you are implementing; an Issue you only mention stays unattached. When you stop work on it, run `issue-tracker.detach`. When you start a Session to implement an Issue, put its `#123` in that Session's Prompt so the new Session attaches itself.
